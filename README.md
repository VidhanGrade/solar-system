# Solar System

A web-based 3D simulation of our Solar System built to explore planetary motion, relative scales, and orbital dynamics.

## Overview

This project provides an interactive visualization of the Sun and planets in our Solar System. Users can inspect individual celestial bodies, toggle orbital paths, and observe real-time planetary motion.

## Features

* **3D Planetary Models:** Rendered celestial bodies with detailed surface textures.
* **Interactive Controls:** Zoom, pan, and rotate around any planet or the Sun.
* **Orbital Mechanics:** Dynamic animation of planetary orbits and rotation speeds.
* **Data Cards:** Key statistics for each planet, including distance from the Sun, radius, mass, and orbital period.

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **3D Rendering:** Three.js / WebGL
